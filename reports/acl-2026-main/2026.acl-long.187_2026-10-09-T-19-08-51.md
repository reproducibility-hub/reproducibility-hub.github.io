# Reproduction report: CTTA-T (ACL 2026, 2026.acl-long.187)

**Verdict: PARTIALLY_REPRODUCED** · result match (after fixes): **NUMBERS_MATCH** · result match as released: **DOES_NOT_RUN** · coverage: **SUBSET** (QA stream, Table 1 only) · codebase completeness: **MINOR_FIXES**



## Summary
- **Main claim checked:** Table 1 (QA continual test-time adaptation, EM/F1 averaged over the tasks of each order, 6 task orders × 2 backbones, XLM-R-base and XLM-R-base-xTune). CTTA-T should beat the non-adapted source model and the TTA/CTTA baselines on every order.
- **Result:** every CTTA-T number in Table 1 (6 orders × 2 backbones × EM/F1, 3 seeds each, plus the Avg column) is reproduced within tolerance: |Δ| ≤ 2.11 points, relative difference ≤ 3.5%, seed std ≤ 0.27. Ours is consistently **0.7–2.1 points higher** than the paper. The source ("base", no adaptation) numbers are also about 1.0–1.9 points higher than the paper's, so the offset comes from the source checkpoints: the paper's own checkpoints were never released, so we used the public COLDQA checkpoints that the paper says it follows. **CTTA-T's gain over the source model matches the paper**: base +1.32 EM on Order 1 (paper +1.62) and +1.62 on Order 4 (paper +1.80); xTune +0.90 (paper +0.89) and +0.98 (paper +0.91). Released baselines (Tent, OIL, CoTTA; 1 seed; CoTTA only on Order 1) all come out well below CTTA-T, as in the paper (ranking preserved), but their absolute values differ a lot from Table 1. Some are clearly *stronger* than reported: base Order-1 Tent is +5.2 EM; OIL is +6.1 EM (base, Order 4), +4.9 (xTune, Order 4) and +4.1 (xTune, Order 1). Others are weaker: CoTTA is −9.9 / −9.0 EM, and xTune Order-1 Tent is −20 EM. So CTTA-T's margin over individual baselines differs from the paper, but its lead does not (flag BASELINE_STRONGER_THAN_REPORTED).
- **Not reproduced / not run:** the Sentiment-Analysis stream (Table 3; no code or data in the release), the SAR/SoTTA/REM/Anti-CF baselines (README: "still sorting them out"), the ablations (Table 2; no switches in the code), CoTTA on Orders 2–6 (only Order 1 was run; the two Order-1 runs took 13 h and 19 h because of 32 augmented forward passes per uncertain batch), and the significance tests.

## What I ran
- Repo: https://github.com/coyil-hub/CTTA-T (commit at clone time, 2026-10-09). It is a fork of `oceanypt/coldqa-tta` (Ye et al., 2022, EMNLP Findings) and bundles transformers 2.x.
- Data: the README link is empty, so I used the public COLDQA release (`huggingface.co/datasets/oceanpty/ColdQA`): NoiseQA-syn/na {keyboard, asr, translation}, MRQA dev SearchQA and TriviaQA-web, and XQuAD zh/ar/es, symlinked as `codebase/download/tasks/<task>.json`. These are the datasets the paper cites (Ravichander et al. 2021; Fisch et al. 2019; Artetxe et al. 2020), with the same task names as the scripts.
- Source models: the README link is empty, so I used the COLDQA checkpoints `oceanpty/xlmr-base-squad` (XLM-R-base on SQuAD with the XTREME config) and `dyyyyyyyy/xTune_squad_XLM-RoBERTa-base` (xTune).
- Environment: Python 3.8, torch 2.1.2+cu121 (the pinned torch 1.7.1+cu110 does not support the H200), numpy 1.24, scikit-learn 1.3.2, tokenizers 0.5.2, sentencepiece 0.2.0. The bundled `third_party/transformers` is used, not a pip install.
- Hyper-parameters, as in the paper and README: lr 1e-5, AdamW, batch size 16, memory_size 1, m = 0.99, restoration p = 0.01, 8 dropout passes. γ = 0.4 and τ = 1.2 for base, γ = 0.4 and τ = 0.6 for xTune. Baselines use the per-method settings hard-coded in the released scripts.
- Commands (run from `codebase/`):
  - Order 1, base, seed 1, with the released script: `SEED=1 bash scripts/continual_short_1.sh xlm-roberta-base tasks $CUDA_VISIBLE_DEVICES ../models/base CTTA-T 0.4 1.2 1e-5 $PWD/download/ ../runs/base_o1_ctta_s1/`
  - All other runs: `bash ../myscripts/run_order.sh <order 1-6> ../models/<base|xtune> <CTTA-T|Tent|OIL|cotta|PL> <γ> <τ> <lr> ../runs/<name> <seed>`. This is the released script's loop and arguments verbatim, with the order taken from Table 5. It was driven by `myscripts/worker.sh` (job queue, 3–4 runs in parallel on the single H200).

- Seeds: CTTA-T used seeds 1, 2 and 3 for all 6 orders and both backbones, as in the paper (3 seeds, averaged). Baselines: 1 seed (seed 1).
- Metric: SQuAD EM/F1 from the released `squad_evaluate` / `evaluate_squad.py` on the online (student) predictions, averaged over the tasks of the order. The source row is order-independent, which is consistent with the paper's identical base numbers for Orders 1–3 and 4–6.

### Settings that differ from the paper
- Source checkpoints: COLDQA's public checkpoints instead of the authors' own (not released). Ours are stronger by about +1.7 EM on the short-sequence tasks (base 54.25 vs 52.52; xTune 58.53 vs 56.96) and +1.0–1.1 EM on the long-sequence tasks.
- torch 2.1.2 instead of 1.7.1 (GPU compatibility).
- Baselines: 1 seed instead of 3. Tent/OIL only on Orders 1 and 4 (the orders the released scripts cover); CoTTA only on Order 1 (too slow). SAR/SoTTA/REM not available.
- GPU: H200 instead of NVIDIA N800.

## As released vs after fixes
- **As released: DOES_NOT_RUN.**
  - Both shell scripts have CRLF line endings, so bash fails (`$'\r': command not found`, syntax error at `do`).
  - The scripts write `results.csv` before the output directory exists.
  - `run_ctta_t.py` imports `xlm_roberta`, `processors.squad` (and through them `bert`, `roberta`, `xlm`), and the scripts call `third_party/evaluate_squad.py`. None of these files are in the repo.
  - The scripts pass `--debias 0|1` to a flag declared `action="store_true"`, so argparse aborts for every method.
  - The README links to the source models and data are empty.
- **After the fixes listed below:** none of them touch the method or experiment logic, and the numbers match (see table).

## Discrepancies
- **[code_vs_paper, major] third_party/run_ctta_t.py METHOD(), CTTA-T branch (topk==-1): loss** — paper: Eq. 1: student minimises soft cross-entropy -sum_y p(y|x,teacher) log p(y|x,student); for high-entropy samples the teacher distribution is replaced by the refined probability distribution (Eq. 4). — code: Student is trained with hard cross-entropy (qa_loss) on the argmax start/end position of the teacher (or of the refined distribution); no soft targets are used. (affects results: True)
- **[code_vs_paper, major] third_party/run_ctta_t.py METHOD(), CTTA-T branch: IPCA / CDA module** — paper: Sec. 3.3: IPCA accumulates covariance over all historical samples X<=t across domains; distance = ||V_t - V_{t+1}||_F^2 and alpha = 1 - distance mapped to a bounded range. — code: A new IncrementalPCA(k=3) is created at step 0 of every domain (each domain runs in a new process), so no cross-domain accumulation; distance is replaced by mean pairwise cosine similarity of the 3x3 component matrices mapped linearly to alpha in [m, 1] = [0.99, 1]; alpha is fixed to m=0.99 on the first batch of each domain. (affects results: True)
- **[code_vs_paper, minor] third_party/run_ctta_t.py METHOD(), IPCA input** — paper: App. D: sequence-level embeddings (one row per input sequence, batch_size x dim) from the encoder embedding layer. — code: 384 randomly sampled token-level vectors (word + position embeddings of the student) from all tokens in the batch. (affects results: True)
- **[code_vs_paper, minor] third_party/run_ctta_t.py argparse --debias / scripts/*.sh** — paper: OIL baseline uses its debiasing as in the original work. — code: Scripts pass "--debias 0/1" but the flag is declared action="store_true", so argparse aborts on every method ("unrecognized arguments"); fixed by declaring it type=int. (affects results: False)
- **[code_vs_paper, minor] README / repository contents** — paper: Sec. 4 / Table 3: a Sentiment Analysis stream (IMDb + Multilingual-Sentiment-Classification, BERT-base trained on SST-2) and baselines SAR, SoTTA, REM, Anti-CF. — code: Only the QA stream is implemented; no SA code/data; SAR, SoTTA, REM, Anti-CF code absent ("still in the process of sorting them out"). Source-model and dataset links in README are empty. (affects results: False)
