## What was run
Environment: `conda create -p ./env python=3.12`, then `pip install -r codebase/requirements.txt accelerate` (torch 2.7.0, nnsight 0.4.6, transformers 4.57.1, numpy 2.5.0). Python 3.12 is needed because numpy 2.5.0 requires it; the README does not give a Python version. We also had to install `accelerate` by hand: `device_map="auto"` needs it, but it is not in requirements.txt. Hardware: 1× H200. The models load in their default bf16.

Commands, all run from `codebase/`:
```
# path search (4 runs in parallel on the one GPU)
python scripts/run_path_search.py --model {meta-llama/Llama-3.1-8B|Qwen/Qwen3-8B} --mode {primary|alternative} \
    --data_path data/<M>/counterfact_sample.json --output_path ../runs/<M>_<mode>.jsonl
# Table 1 (16 runs), using OUR re-computed path files

    {representation_knockout|downstream_injection|path_continuation|global_broadcast} --path_results_path ../runs/<M>_<mode>.jsonl

```
`scripts/suff_driver.sh` chained the sufficiency runs after each path search finished. `scripts/make_status.py` builds the comparison table.

There are no deviations from the paper's setting: same models, the same 2000-prompt samples (released, and also regenerated identically), seed 42, greedy argmax.

**The paper's claims hold:**
- primary paths are short and early (mean `l_attr` 4.6 / 8.0);
- many paths are non-contiguous (33.1% / 78.65% skip at least one layer);
- alternative paths exist for more than 80% of facts and are longer and deeper;
- knocking out the representation at `l_attr` breaks recall in more than 93% of cases;
- the `l_attr` representation alone is often insufficient (downstream-injection failure 45% / 56% on primary paths).

## Discrepancies
We found no code-vs-paper discrepancy that affects the results. Things we checked:
- **`isolate`.** The code patches counterfactual activations only into the first layer after each path layer and lets the rest compute. This is equivalent to the paper's definition: the entity positions are patched over the whole entity span, and the token prefix is shared, so the skipped layers reproduce the counterfactual run at the entity positions.
- **Search prompt.** The search runs on the counterfactual prompt with clean entity activations patched in, which is again equivalent.
- **`l_attr` field.** The `l_attr` field in the primary results is the value *before* the footnote-4 redefinition (mean 4.81 / 8.41). The paper's statistics and the sufficiency script both use the last path layer, which is consistent with the paper.

Notes that are not code discrepancies:
- **Qwen alternative skip size.** The paper reports a mean skip size of 10.4. The authors' own released path file gives 9.60 under the definition that reproduces the Llama numbers and the Qwen primary number exactly. No definition we tried gives 10.4: the mean over skipping paths only is 9.92. So the paper's figure for this one statistic appears to be off.
- **Qwen primary path length.** The paper gives 7.97 for both the mean primary `l_attr` and the mean path length. That looks like a typo, but it is genuinely true: 7.973 and 7.9715.
