**PARTIALLY_REPRODUCED.** Result match `NUMBERS_MATCH` (as released: `NUMBERS_MATCH`). Coverage `SUBSET`. Codebase completeness `MISSING_SCRIPTS`.

- **What reproduces.** Every For-Value number we could run with the released code reproduces:
  - **Table 1:** all 12 numbers (3 LLM tasks × Qwen2.5-1.5B / Llama-2-13B-chat).
  - **Table 2, mislabeled-data detection:** Qwen2.5-VL-3B and Llama-3.2-11B-Vision.

The results come close (style AUC 0.889 vs 0.895 for Qwen, 0.977 vs 0.974 for Llama), but because the pipeline is ours they are marked `NOT_COMPARABLE`.

Settings that differ from the paper:
- **Hardware:** H200 instead of A100/H100, so absolute runtimes are not comparable.
- **Model mirrors:** `NousResearch/Llama-2-13b-chat-hf` stands in for the gated `meta-llama/Llama-2-13b-chat-hf`, and `unsloth/Llama-3.2-11B-Vision` for the gated `meta-llama/Llama-3.2-11B-Vision`. Both are ungated, weight-identical mirrors.
  - The unsloth mirror's `tokenizer_config.json` adds `"padding_side": "left"`. The original config (checked through the alpindale mirror and other copies) has no `padding_side`, so it defaults to right padding.
  - With left padding, the hard-coded `LLAMA_START_INDEX=14` in `forvalue_VL_optimized.py` falls on padding. Two things then go wrong. First, the run crashes: the `<|image|>` id 128256 lands in the vocabulary, which is outside the LM-head range. Second, after a one-line vocabulary fix, the scores are wrong: AUC 0.703 / Recall 0.310.
  - With the original right padding, the unmodified code reproduces the paper exactly.
  - This is tokenizer handling for the mirror, not a code change. The left-padding diagnostics are kept in `runs/diagnostic_leftpad_vocabfix/`. The temporary one-line fix has been reverted.

## Discrepancies
1. **code_vs_paper, major (Recall metric for mislabeled-data detection).** In `forvalue_VL_optimized.evaluate_metrics`:
   - **Paper (App. A.5.4):** the pseudo-label is 1 only if the training label matches the valuation point's label *and* the sample is clean.
   - **Code:** AUC uses that definition, but Recall counts *any* clean sample (`label==0`) among the top `n = 100·ratio`, ignoring the class.
   - **Effect:** recomputed with the paper's definition (`scripts/vl_recall_check.py`), Qwen2.5-VL-3B Recall at r=0.5 falls from 0.966 to 0.834. Llama-3.2-11B-V is unchanged (0.999).
   - Under the paper's definition, the Qwen For-Value recall would fall below the reported HyperINF value (0.916). We cannot tell which definition the baselines used.
2. **code_vs_paper, major (`LLAMA_START_INDEX = 14` for Llama-Vision).** In `forvalue_VL_optimized.py`:
   - With the original right-padded tokenizer, the prompt `<|image|><|begin_of_text|>Q + "It is a " + label` is 15 tokens.
   - Index 14 is therefore the label token itself. The only scored position is the hidden state *at the label token* predicting the following pad token, with a 1-token vocabulary (the pad id).
   - That is not Eq. (1) summed over the response tokens. Scoring the response tokens instead (`--start_index 794/798` under left padding) gives AUC ≈ 0.67 and Recall ≈ 0.
   - The paper's Llama mislabel numbers match only this implicit configuration. The implementation also depends silently on the tokenizer's padding side: the unsloth mirror's left padding gives AUC 0.703.
3. **code_vs_paper, minor (vocabulary).**
   - **Paper:** V̂ is the in-batch set of sample tokens.
   - **Code, LLM-selection script:** the README commands use `topk_unique`, a vocabulary of each position's top-5 predictions, further reduced by `--topk_abs 3`. They also use `--lowest_likelihood_ratio` position filtering, which the paper does not describe.
   - **Code, Table 1:** the `total_unique` mode matches the paper's numbers. `topk_unique` does not (Qwen sentence transformations Recall 0.771).
4. **code_vs_paper, minor (noisy data).**
   - **Paper (Table 11):** Noise-Huatuo has 2981 clean / 2019 noisy samples.
   - **Release:** `Medical_noise_split_new` has 2942 / 2058. The cause is `noise_huatuo.py`, which uses the unseeded `random.random()` for the 40% noise decision.
   - Similarly, `dog_cat.py` defaults to `mislabel_ratio=0.6`, and the r=0.5 set used in Table 2 is not shipped.
5. **paper_internal (Table 2 subject generation).**
   - **Text (Sec. 5.1):** For-Value "achieves the highest AUC and recall scores for both models, consistently outperforming all baselines".
   - **Table 2:** Qwen2.5-VL-3B For-Value Recall is 0.897, below HyperINF's 0.902.
