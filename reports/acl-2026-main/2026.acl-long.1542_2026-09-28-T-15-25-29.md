# Reproduction report — Anchoring the Cache (HalluKV), ACL 2026 (2026.acl-long.1542)

**Verdict: PARTIALLY_REPRODUCED** · result match: **TREND_MATCH** (ROUGE only; the hallucination metric could not be run) · coverage: **SUBSET** · codebase completeness: **MISSING_CORE**

## Summary
- **Code.** The paper links https://github.com/FYYFU/HeadKV. That repo is the authors' earlier *HeadKV* (ICLR 2025) code (last commit 2025-03-10). It includes SnapKV, PyramidKV and HeadKV prefilling compression. It does **not** include HalluKV itself (the decoding-phase eviction of generated KV on retrieval heads with mask ratio α). It also has no FineSurE/hallucination evaluation and no summarization run/eval script. I implemented HalluKV myself from Sec. 4 (Eq. 4–7).
- **Main metric blocked.** The paper's headline numbers (hallucination score, Table 1 "Hal.", the 3.36× and 5.48-point claims) come from FineSurE run on **Claude-3.7**. No Anthropic API key is configured here, so no hallucination numbers were produced. All 36 Hal. comparisons are `NOT_COMPARABLE`. As a supplementary open-source proxy I used AlignScore-large (the paper uses it in Table 5, but only for other models, so there are no paper numbers to compare against).
- **What was run.** Table 1 for **Llama-3-8B-Instruct** (1 of 6 models): SnapKV, PyramidKV, HeadKV (released code) and HalluKV (my implementation). KV budgets 64/128/256/1024, GovReport and MultiNews (LongBench, all 200 examples each), with ROUGE-L. Other models were not run because the repo ships retrieval-head scores only for Llama-3-8B-Instruct and Mistral-7B-v0.2.
- **Findings.**
  - Absolute ROUGE-L is about 0.4–1.8 points below Table 1 for *all* methods, including the released baselines. 16/32 cells are within tolerance.
  - The paper's ranking holds in every cell: HalluKV > HeadKV > SnapKV ≈ PyramidKV.
  - HalluKV beats HeadKV on ROUGE-L in 8/8 cells: +0.78 on average vs +1.13 in the paper. All 9 gain comparisons are within 1 point.
  - My HalluKV writes about 15–25% longer summaries.
  - Raw AlignScore is mixed: HalluKV is worse than HeadKV at KV=64 (both datasets) and KV=128 GovReport, better elsewhere, +0.78 on average.
  - With length controlled, AlignScore favors HalluKV in 6/8 cells (+2.9 on average). This is weakly consistent with the paper's direction, but it is only a proxy.
  - Compression hurts faithfulness monotonically (SnapKV AlignScore 36.9 at KV=64 vs 56.6 at KV=1024 on GovReport), which is consistent with the paper's motivation study.

- `score_rouge.py` uses the repo's LongBench `metrics.rouge_score` (ROUGE-L F from the `rouge` package, max over references, ×100).
- `score_align.py` computes AlignScore-large with nli_sp, summary vs. full source, ×100.
- `score_align_lenctrl.py`: for each example, both the HeadKV and HalluKV summaries are cut to the same number of sentences (the smaller of the two) before AlignScore.
- `make_tables.py` builds the tables and `comparisons.json`.

Settings (paper vs. mine):
- Same as the paper: model, datasets and splits (LongBench, 200 each), budgets, β=1.05, window w=8, α=0.2, greedy decoding, max 512 new tokens, input truncation to 7950 tokens (middle truncation, repo default).
- Not specified in the paper; my choices:
  - HeadKV budget allocation uses the retrieval-**reasoning** head distribution (`head_choice=reason`, the README default).
  - HalluKV's masked heads are the top ⌊0.2·1024⌋ = 204 heads by the Wu et al. **retrieval** head scores (`Meta-Llama-3-8B-Instruct_retrieval_heads.json`), as Sec. 4.2 describes.
  - Masked heads attend only to their compressed prefill KV at every decoding step (Eq. 7). The current token's own key is excluded.
  - Sensitivity check: selecting masked heads by the retrieval-reasoning scores instead gives ROUGE-L 22.99 / 24.95 (GovReport / MultiNews, KV=128) vs 22.15 / 24.53 with my default and 24.04 / 26.19 in the paper. Its AlignScore is 48.51 / 64.79.
- Not run: the hallucination metric (FineSurE, Claude-3.7), models other than Llama-3-8B-Instruct, and Tables 2–5 and Figures 2, 3, 5, 6, 8.

## Why not fully reproduced
1. **Missing API key.** The main metric needs Claude-3.7 (FineSurE), so none of the paper's hallucination numbers could be checked. That includes the 3.36× increase, the 5.48-point average reduction, and Tables 2–4.
2. **Missing core code.** HalluKV itself is not in the released repo. My implementation follows the paper, but details are unspecified: which head-score file is used, whether the current token is attended, and the HeadKV head_choice.
3. **Partial coverage.** Retrieval-head score files exist only for 2 of the 6 models, and I ran only one model.
4. **Unexplained ROUGE offset.** Absolute ROUGE-L is systematically about 1 point lower even for the released baselines. This is likely an evaluation or config detail (different ROUGE implementation, prompt or chat template, library versions) that I could not identify.
