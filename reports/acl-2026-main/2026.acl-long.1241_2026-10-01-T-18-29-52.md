## What the paper claims (targets)

## What I ran
- Repo: https://github.com/SeonjeongHwang/ReCo (commit `ada2b3a`), cloned into `./codebase`. Test data is `data/ReCo.test.json` (498 statements; 409 for TL).
- Env: `conda create -p ./env python=3.11`, then `pip install vllm evaluate openai jsonlines scikit-learn openpyxl pandas accelerate`. Versions: vllm 0.30.0, transformers 5.18.0, torch 2.13.0+cu130. Hardware: 1x H200.
- Models: `mistralai/Mistral-7B-Instruct-v0.3`, `mistralai/Mistral-Small-24B-Instruct-2501`, `Qwen/Qwen2.5-7B-Instruct`, `Qwen/Qwen2.5-32B-Instruct`, `Qwen/Qwen3-32B` (the names used in the code's NICKNAME2NAME).
- Main runs: `scripts/launch.sh <model>`, which runs `scripts/run_vllm.py --model <model> --groups main,fine`. For Qwen3: `scripts/launch.sh qwen3-m qwen3`.
  - `run_vllm.py` imports the released `es_inference`, `tl_inference`, `es_fine_inference` and `tl_fine_inference` modules and calls their own `main()`. The released code still does argument parsing, prompt construction from `prompts/`, answer extraction, majority voting, `evaluation.py` scoring and saving `result.json`.
  - The only thing replaced is the `Generator` class (HF `model.generate` with batch 8). It is swapped for a vLLM drop-in with the same `model_generate(input_prompts, do_greedy)` interface: same `apply_chat_template(..., enable_thinking=is_reasoning)`, prompts passed as text (so BOS handling is the same as the HF path), greedy decoding (temperature 0) or top-k 20 / top-p 0.8 / T 0.7 with n=10, `max_tokens` 1000 (30000 for thinking), seed 2025, and the flashinfer sampler disabled (it needs nvcc).
  - Why vLLM: the HF loop took about 6.6 min for one greedy CoT config on the 7B model. The 10-sample configs on 24B/32B models would have taken several days.
  - Configs per model: ES and TL, each with SP {0,1,few}, CoT greedy {0,1,few} and CoT-SC (10 samples) {0,1,few}. Fine subtasks: falsify, cnt_evidence, inference, paraphrasing, transformation (few-shot CoT, greedy). Qwen3-32B: ES/TL zero-shot CoT greedy, with and without `--is_reasoning`.
- As-released check with the unmodified HF code: `cd codebase && sh run.sh qwen-s 1 es.sp zero` and `sh run.sh qwen-s 1 es.cot one`. Outputs are copied to `outputs_hf_as_released/`.
- Scoring and comparison: `scripts/compare.py` writes `comparison.json`, `scripts/write_status.py` writes `comparison_table.md`, and `scripts/tl3_alt.py` writes `tl3_alt_metric.json`.
- Settings that differ from the paper:
  - Inference engine is vLLM instead of HF transformers. Greedy CoT outputs differ slightly because bf16 batching is not bit-identical; the paper used 2x A100.
  - Gemma2 and the GPT models were not run.
  - All other settings (prompts, demos, sampling parameters, data) are the released ones.

## Discrepancies
1. **code_vs_paper, major: TL 3-level scoring (`evaluation.py::tl_evaluate`).**
   - What the paper says (Sec. 4): TWM and TP are mapped to WM and P for both predictions and single-sentence gold labels.
   - What the code does:
     - It never converts gold TWM/TP.
     - It collapses a predicted TWM/TP only when the gold label is WM/P.
     - It computes F1 with `labels=[0,1,2]`. As a result, the 80 gold-TWM/TP items count as false positives when predicted WM/P, and are ignored when predicted TWM/TP. Stray TWM/TP predictions are not counted as false positives.
   - Effect: the paper's numbers come from this code, but they don't correspond to the protocol the paper describes. Re-scoring the authors' own released predictions with the described protocol (`scripts/tl3_alt.py`, `tl3_alt_metric.json`):
     - Mistral-24B CoT-SC 0-shot: 82.0 → 77.7
     - Qwen2.5-32B CoT-SC 0-shot: 74.0 → 78.8
     - GPT-4o best: 73.9 → 77.4
   - Under the described protocol, Qwen2.5-32B rather than Mistral-24B is the best TL-3 model, though open models still match GPT-4o. On our outputs, the same re-scoring gives Mistral-24B SC 0-shot 83.9 → 74.5. The best Mistral-24B config is then 78.2 and the best Qwen2.5-32B is 76.9, so the ranking between these two depends on the protocol and on run-to-run noise.
2. **paper_internal: self-consistency hyperparameters.** Sec. 4 says top-k=20, top-p=0.8, T=0.7 for all models. Appendix C says each model's own default sampling parameters were used. The code matches Sec. 4.
3. **paper_internal: "trivial item" filtering.** Sec. 4 says items that GPT-4o solves zero-shot are excluded. But Table 1 and the released test set have all 498 statements, and all models are scored on all 498. The sentence may refer only to how exemplars were chosen.
