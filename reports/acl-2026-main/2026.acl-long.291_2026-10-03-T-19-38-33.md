## Discrepancies
- **[code_vs_paper, major] run.py InContextLLM._update_vec / _average_and_normalize (iterative stage)** — Paper: Algorithm 3 line 11: z_j^{t+1} = MeanPooling{z_k^t : x_k in O_j^t} (mean of the LLM-selected texts' BoT vectors only), then L2-normalise. Code: The text's own current BoT vector is included in the mean: emb = (z_j^t + sum_k z_k^t) / (1 + |O_j^t|), then L2-normalise (a damped update). Affects results: True.
- **[code_vs_paper, minor] run.py argparse defaults** — Paper: m = 30 candidates (3 calls x c = 10), d = 1,024 initial representatives. Code: Defaults partition_num=4 (m=40) and initial_dimension='full' (d=N); the README command passes --partition_num 3 --initial_dimension 1024, matching the paper. Affects results: False.
- **[code_vs_paper, minor] prompt_template.py vs Table 2** — Paper: Answer format: 'Only provide the final selection ... listing their numbers if they match the Target Utterance intent or request. 1. If Candidates 3, 4, and 9 match ... 2. If no Candidates match ...' Code: Slightly different wording/numbering ('1. Only provide the final selection ... by listing their numbers. 2. If Candidates 3, 4, and 9 match ... 3. If no Candidates match ...'); GoEmo/StackOverflow instruction lacks the blank line. Same content. Affects results: False.
- **[code_vs_paper, minor] cluster_dataset.py (GCD split) vs Table 1 / Table 7** — Paper: Table 7: Bank77 train = 9,003, so |Du| = 30% = 2,700 (Table 1). Code: Uses ALUP's banking/train.tsv which has 9,016 rows -> int(0.3*9016) = 2,704 unlabeled texts (5,780 total). Same procedure, 4 extra texts. Affects results: False.

No paper-internal inconsistencies found. All averages in Table 4 match their per-dataset entries, and Table 10's Gemma row equals Table 4/5.
