## Summary

- **Table 1 (main result, avg. SOCM on 499,500 Wikipedia pairs, 12 models):** all 12 values reproduced (max |diff| 0.0011). All 8 backbone→fine-tuned deltas match in sign and size, including the one increase (MiniLM→all-MiniLM-L12-v2, +0.071).
- **Appendix Tables 5 / 6 (MS MARCO, MS MARCO hard negatives):** all 24 values within 1.4% relative.
- **§7 / Fig. 5 / Table 2:** full MTEB(eng, v2), 41 tasks, run with the released `run_mteb.py` for all 12 models. Spearman ρ(SOCM, MTEB) = **−0.678 (p = 0.015)** and ρ(S(X)/‖μ‖², MTEB) = **−0.622 (p = 0.031)**, identical to the paper.
- **§6 / Fig. 4:** layer-wise λ, r, C and S(X)/‖μ‖² for BERT vs GTE_base (plus E5_base, Unsup-SimCSE, MiniLM, E5_small, GTE_small, all-MiniLM; Figs. 6–10) and within-text average cosine (Figs. 11–16) were computed. The BERT/GTE_base curves match Fig. 4: λ<1 everywhere; r and S(X)/‖μ‖² of GTE_base fall to ≈0.18 and ≈0.09 at the last layer, vs ≈1.1 and ≈1.6 for BERT.
- Finding of note: the released d_Σ uses float32 `eigh` on rank-deficient 768×768 covariances, which biases d_Σ low. The paper's absolute SOCM values depend on these numerics; an exact float64 computation gives SOCM 0.003–0.011 higher, with identical model ranking and identical MTEB correlation (see Discrepancies).

## What I ran

Environment: conda env (python 3.12.8) with the exact `uv.lock` versions (torch 2.8.0+cu128, transformers 5.1.0, sentence-transformers 5.2.2, mteb 2.7.26), installed via `uv export --frozen` + pip. Scripts were run with the env's python instead of `uv run python3`. 1× H200.

1. Data: `scripts/data/make_{wiki,msmarco,hard_negatives}_dataset.sh` (seed 0). The sampled wiki_1000 set is the authors' set: the two Fig. 1 texts appear as ids 335/739, as in their notebook.
2. SOCM: `src/calc_socm_pairwise.py` (wiki_1000, msmarco_1000) and `src/calc_socm_hard_negative.py` (hard_negatives_50000), batch 64, all 12 models (= `scripts/calc_socm.sh`).
   - BERT/wiki and all 12 hard-negative runs used the released scripts unmodified.
   - The released pairwise script recomputes Σ_i^{1/2} (a 768×768 eigh) for every pair, ~1.9–3 h/model on a shared GPU. To fit the budget, the other 11 wiki models and all 12 MS MARCO models used `myscripts/socm_pairwise_cached.py`. It is the same code (it imports the released `encode_embeddings`; the BW routine is copied verbatim), with Σ_i^{1/2} cached per text. Its output was **bitwise identical** to the released script on BERT/wiki (max |diff| = 0.0 over 6,400 pairs for d_μ, d_Σ, SOCM).
3. Layer-wise: `src/calc_{token_concentration,lambda,r,C,avg_cos}.py` for the 8 BERT-family models, and `src/calc_last_token_concentration.py` for all 12 (= the README scripts).
4. MTEB: `src/run_mteb.py --benchmark_name 'MTEB(eng, v2)' --batch_size 64` for all 12 models (`run_mteb_all.sh`). MindSmallReranking is CPU/RAM heavy (50–66 GB RSS, 0.5–7 h per model). To overlap work, `myscripts/mteb_prefill.py` pre-filled the mteb cache with the other 40 tasks using the identical model construction. The released `run_mteb.py` then ran MindSmall and produced the final 41-task averages (its `assert len(...)==41` passed for all 12).
5. Analysis: `myscripts/analyze.py` (tables, Spearman, layer means → `summary.json`), `myscripts/mteb_from_cache.py`, `myscripts/exact_vs_released.py` (precision check, 20k random wiki pairs/model).

Settings that differ from the paper: none in the experiment. GPU: H200 instead of RTX 6000 Ada. Unsup-SimCSE-mean is the authors' released checkpoint; not re-trained (training is not part of the claims).

## Discrepancies

- **code_vs_paper** (minor, affects results: True) — *src/utils/distance.py calc_batched_bures_wasserstein_squared_distance (used for d_Sigma, Eq. 6)*. Paper: d_Sigma is the (scaled) Bures-Wasserstein distance tr(S1+S2-2(S1^1/2 S2 S1^1/2)^1/2)/4. Code/other: computed with float32 eigh on 768x768 rank-deficient covariances (+1e-9 ridge, eigenvalues clamped at 0); sqrt of round-off eigenvalues inflates the trace term, so d_Sigma is biased low by ~0.01. Exact float64 low-rank computation gives avg SOCM +0.003..+0.011 higher (e.g. GTEbase wiki 0.0175 -> 0.0277, BERT 0.396 -> 0.405); model ranking (rho=1.0) and MTEB correlation (-0.678) unchanged.
- **code_vs_paper** (minor, affects results: True) — *Section 5.2 / Figure 1 qualitative example vs notebooks/qualitative_analysis.ipynb*. Paper: BERT SOCM = 0.618, GTEbase SOCM = 0.024 for the Woolf/Ghiz pair. Code/other: released pipeline (and the authors' own notebook output) gives 0.6116 and 0.0170; notebook comment says values differ due to computing environment.
- **paper_internal** (-, affects results: False) — *Section 6.2 'Residual Connection (r)' text vs Figure 4b*. Paper: In GTEbase, r was lower than in BERT across layers. Code/other: Figure 4b itself (and our recomputation: layer 1 GTEbase 4.68 vs BERT 3.41) shows GTEbase above BERT at layer 1.
