## Discrepancies
1. **code_vs_paper (major): DeepSeek model.** The paper evaluates "DeepSeek-V3", but the code's `ALLOWED_MODELS` only contains `deepseek-ai/deepseek-llm-7b-chat`. Running the 7B chat model reproduces the "DeepSeek-V3" row closely, so the row is most likely mislabeled.
2. **code_vs_paper (major): Drift definition.** Paper Eq. 7 counts only turns where a per-turn present-day answer exists **and differs** from gold. The code differs in two ways:
   - It uses one chain-level `present_day_answer` for every follow-up turn, even when the turn asks about a different property. Example: the present-day *employer* is compared against a *member of* question.
   - It never checks present ≠ gold. In the full dataset, 12.5% of drift-"eligible" follow-up turns have present == gold.

   The reported Drift numbers are therefore computed differently from the formula. Our Drift values come from the code's definition, as the paper's presumably did.
3. **code_vs_paper (minor): Sampling.** Appendix A.2 says "up to 100,000 chains from each stratum". The code splits a *total* of `max_chains` evenly across (family, length) strata. The self-conditioned subset is just the first `self_max_chains` chains of the bucket-ordered sample, so it covers only change_point, distinct_count, multi_turn_chain and bridged_multi_pid chains of length 4–5.
4. **code_vs_paper (minor): Sample sizes.** The README/sbatch defaults (50k/10k) differ from the paper's Table 7 (100k/20k).
5. **paper_internal: Table 4 vs Table 6 vs text.**
   - Table 4 (Qwen-2.5 Gold Final@1, L=2..6): 0.481/0.525/0.556/0.572/0.515.
   - Table 6 (same model and setting): 0.19/0.13/0.52/0.63/0.62.
   - The text says "0.48 at length two to 0.59 at length five", which matches neither table.
6. **paper_internal: Table 9 vs Table 3/7.** Every per-position Acc@1 in Table 9 is ≤ 0.164, yet the overall Gold Acc@1 is 0.306. An average of values that are all ≤ 0.164 can't be 0.306.
7. **paper_internal (no effect on results).** The text says Gold drift is "≈0.02 to 0.08", but Table 3 includes 0.084 for Mistral (and higher values for the proprietary models).
