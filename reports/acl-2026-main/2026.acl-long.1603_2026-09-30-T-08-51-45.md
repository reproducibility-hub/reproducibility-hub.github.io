# Reproduction report — ATGL: An Adaptive-Threshold Global Loss for Document-level RE (2026.acl-long.1603)

**Verdict: PARTIALLY_REPRODUCED** — result match **NUMBERS_MATCH** (both after-fixes and as-released; no source edits were made), coverage **SUBSET**.

The release implements ATGL only for the ATLOP backbone on Re-DocRED (BERT-base and RoBERTa-large). I ran both configurations with the released scripts, unmodified, over 5 seeds each. Every number is within 1 F1 point of the paper's ATLOP+ATGL Re-DocRED results (Table 2, repeated in Tables 3 and 9). The rest of the paper's main experiments (DocGNRE, DWIE and CDR, the other five backbones in Table 2, and the baseline losses in Table 3) have no code in the release, so I did not run them. That is why coverage is SUBSET.

## What was run
- Repo: https://github.com/xhm-code/ATGL (cloned into `./codebase`, HEAD as of 2026-09-30). The data came from the repo's own `dataset/redocred.tar.gz`, extracted as the README says.
- Environment: conda env with Python 3.9, torch 2.1.2+cu121, transformers 4.20.1, numpy 1.26.4, opt-einsum and ujson. The README lists Python 3.7 / torch 1.12+cu113, but that CUDA 11.3 build cannot target the H200 (sm_90), so I used newer torch. No code changes were needed.
- Commands (from `codebase/`):
  - `bash scripts/run_bert_redocred_seeds.sh` (seed 66; lr 4e-5; 20 epochs; batch 4; α = p_weight = 16.5)
  - `bash scripts/run_roberta_redocred_seeds.sh` (seed 66; lr 2e-5; 20 epochs; α = 16.5)
  - `bash scripts/test_bert_redocred_seeds.sh`: re-evaluating the saved checkpoint gives identical numbers.
  - Extra seeds 62, 64, 68 and 70 used `run_seeds.sh`, my wrapper outside the codebase. It runs exactly the same arguments as the released scripts and changes only `--seed`. The paper says results are "averaged over multiple random seeds" but does not say which seeds; the release uses only seed 66.
- Supplementary sanity baseline, not in the release: `atl_baseline.py` / `run_atl.sh`. This is the same ATLOP model and the same training settings, with the loss swapped for the original ATLOP ATL loss (copied from wzhouad/ATLOP, applied by monkeypatching, without touching the codebase). It ran over 3 seeds. It checks that ATGL's gain over ATL shows up under identical settings. It is not a reconstruction of the paper's baseline numbers, which the paper cites from Xu et al. (2025a).
- Hardware: 1× H200. BERT took about 15–25 min per run and RoBERTa-large about 40–45 min (two runs shared the GPU at a time).
- Settings that differ from the paper: GPU (H200 instead of RTX 3090), library versions, and seed choice (62/64/66/68/70). Everything else follows the released scripts.

## Discrepancies
- code_vs_paper (minor): `scripts/run_*_redocred_seeds.sh` train for 20 epochs, but Table 8 describes Re-DocRED training "for 30 epochs" (30 is also the `train.py` default). The paper states no other epoch count.
- code_vs_paper (minor): the paper reports results "averaged over multiple random seeds", but the released scripts run a single seed (66) and the paper never names the seeds.
- code_vs_paper (minor): at inference, `ATGLoss.get_label` also caps predictions at the top-4 logits (`--num_labels 4`, ATLOP's default). The paper describes inference only as "relations whose logits exceed the threshold".
- paper_internal: the ATL/ATLOP baseline on Re-DocRED (BERT, test) is 74.02 F1 / 73.22 Ign-F1 in Table 2 but 73.29 / 72.46 in Table 3. Both tables attribute it to Xu et al. (2025a).
- paper_internal: ATLOP+ATGL on DWIE (BERT) test Ign-F1 is 70.55 in Table 2 but 70.05 in Table 3.
- paper_internal: CMM on Re-DocRED (ATLOP, BERT, test) is 76.12 / 74.76 in Table 3 but 76.10 / 74.80 in Table 6. Both are "from the original CMM paper".
