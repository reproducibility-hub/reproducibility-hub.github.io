## What the paper claims
Pretrained GPT-2 (124M) has an attention sink at position 1. It comes from three things working together: the query bias b_Q, the first-layer MLP's transform of the position-1 positional embedding (the "EPE"), and coordinate-level structure in W_k. The paper supports this with four structural analyses (Figs 1–4, 7) and ten causal interventions (Table 1, Fig 5). These are run on 300 examples (100 each from SST-2, GSM8K and HumanEval), each truncated to 40 tokens, using layers 4–11.

The paper's other claim is that "each component is dispensable in other architectures". This is a literature argument with no experiments behind it, so there was nothing to reproduce.

## What I ran
I created the env with `conda create -p ./env python=3.11` and ran `pip install -r codebase/requirements.txt` (torch 2.10.0, transformers 5.3.0, datasets 4.8.4). Then I ran the seven README commands without changing them. The driver is `run_all.sh`, outputs are in `./results_repro`, and logs are in `./logs/`. I kept a copy of the authors' shipped results in `./released_results`.

## Discrepancies
1. **paper_internal** — Swap EPE positions. Sec. 3.2.6 says the swap is "between positions 1 and 28". Appendix B.1 describes a swap between positions 1 and 2. The code (`intervention_d_swap_epe_normalized` / `_e_swap_pe`, which swap 0-indexed positions 0↔1) and Fig 5 both follow the 1↔2 version. The reported numbers come from 1↔2, so the "28" looks like a typo. This does not affect the results.
2. **paper_internal (wording)** — Sec. 3.2.6 says Wk "columns" are zeroed, while Sec. 5.3 says "rows". The code zeroes the input-coordinate slice `wk[:, idx]`, which matches the stated intent. This does not affect the results.

I found no code_vs_paper discrepancies.
