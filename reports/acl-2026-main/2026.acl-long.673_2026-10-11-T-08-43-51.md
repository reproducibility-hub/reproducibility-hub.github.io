### Why only partially reproduced
No OpenAI API key is configured. In this paper, GPT-4o is more than a judge:
- it is one of the three evaluated VLMs;
- it generates and answers the Visual Fidelity verification questions;
- it produces Informativeness and the VizWiz hard negatives;
- GPT-4o-mini paraphrases each question–answer pair into the NLI hypothesis;
- GPT also computes the LAVE soft correctness labels for VizWiz and parses MMMU-Pro answers.

None of these steps could be re-executed. What I did:
1. **Recomputed the main tables from released data.** I recomputed Table 1/2 from the released per-instance artifacts with the repo's code. I re-executed every step that uses open models on those artifacts: the NLI entailment model for Simulatability and Contrastiveness, and Vera for Plausibility. Visual Fidelity and Informativeness come straight from the released GPT outputs.
2. **Re-ran the supporting experiments that need only open models:**
   - Table 13: uncertainty baselines;
   - Table 10: Contrastiveness hard-negative ablation;
   - Tables 16/17: Visual Fidelity with Qwen2.5-VL-7B and Gemma-3n-E4B as open verifiers;
   - LLaVA/Qwen answer and explanation generation.
3. **Could not reproduce the user studies.** The headline 11.1% accuracy gain and 15.4% over-reliance reduction (Figures 4–8) come from human-subject studies. No participant data or study code is released.

### Settings that differ from the paper
- **GPT-dependent quantities are not re-run.** VF, Informativeness, the hypotheses and hard negatives, LAVE labels and all GPT-4o predictions are taken from the released artifacts.

## Discrepancies
1. **paper_internal — Section 3 vs Appendix D.1 / Table 5.** Section 3 says GPT-4o masks answers and paraphrases the question–answer pairs. The appendix and the code instead use a rule-based regex mask and GPT-4o-mini for the paraphrase.
2. **paper_internal — Table 17 vs Table 2.** For the GPT-4o verifier, VF ECE is 0.207 vs 0.197 (A-OKVQA, LLaVA) and 0.136 vs 0.139 (VizWiz, Qwen).
3. **code_vs_paper, minor — `visual_fidelity.py`.** The default VF question generator and verifier is `gpt-4o-2024-08-06`, while the paper's GPT-4o is `gpt-4o-2024-05-13`.
4. **code_vs_paper, minor — `ece_analysis.py`.** ECE uses soft LAVE labels for the first six metrics but binarised labels for Prod and Min. On VizWiz, LLaVA's Prod ECE is 0.290 as reported, versus 0.265 with soft labels.
5. **code_vs_paper, minor — Appendix K.3.** The paper describes a "verifier swap" on "held-out slices". The code's `__main__` has the open model generate the questions too, and runs on the full 500-question sets.
6. **code_vs_paper, minor — MMMU-Pro split.** Section 3 says data comes from "the validation set". The code uses the MMMU-Pro test split, which is the only split; Appendix L.2 describes this correctly.
