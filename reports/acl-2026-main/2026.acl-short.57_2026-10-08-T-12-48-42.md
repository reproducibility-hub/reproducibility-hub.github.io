**Verdict: FAILED** (result match `NO_MATCH`, coverage `FULL`, codebase completeness `MAJOR_FIXES`)

- **Result match (after fixes): `NO_MATCH`.** Most absolute numbers land within tolerance of the paper. The paper's central claim does not hold: the full FL-MSCL model (prompt + supervised contrastive learning) is not better than its ablations. The paper reports +1.6 to +8.9 F1 for the full model over "w/o Prompt + w/o Contrast" on every benchmark. We also ran the code's own default configuration (deberta-large) as a supplement. There, FL-MSCL's absolute numbers come close to the paper (unified macro-F1 86.1 = paper), but the ablation gain is equally absent (+0.7 vs paper +5.4 on the unified task; −2.7 vs +8.9 on MOH-X).

## Why this is not a reproduction
1. **The method's claimed gains do not appear.** With the paper's settings and the authors' own code (prompt block re-enabled), all four ablation variants score within ~1–3 F1 of each other. The same holds with the code's own deberta-large defaults. The full model is worst or near-worst on the unified task, MOH-X and VUA-Verb. Only TroFi shows a gain, and it is about a third of the reported one.
2. **The w/o-both baseline is much stronger than reported.** It shrinks or reverses every reported improvement.
3. **Probable reasons** (we found no bug in our runs that would explain the gap):
   - The prompt mechanism in the code is weak:
     - the three "Multi-Ex" metaphor exemplars are identical;
     - the literal exemplar is static;
     - candidates come only from the first 10 sentences per label of the file being processed;
     - on binary test sets the metonymy/simile slots are empty.
   - The exact unified data version (`train3.6.txt` etc.) is not released.
   - The paper reports single runs with no variance, and differences of this size are within the seed noise we observe.
4. **Data leakage across the benchmark evaluations.** A single model trained on the unified `train.txt` is evaluated on all benchmark test sets, but `train.txt` contains:
   - 46% of the VUA-18 / VUA-Verb test sentences (VUA-Verb: 1,221 of 1,228 overlaps with the same label);
   - 47% of VUA-20 test sentences;
   - 24% of MOH-X test sentences;
   - 12.5% of the unified test set.

   In addition, `VUA18_filtered_test.txt` and `VUAverb-test.txt` contain the same 2,679 sentences, labeled differently. The very high VUA-Verb scores (≈86–89 for every variant, vs. ~77 for prior SOTA) are therefore not evidence of method quality.

## Discrepancies
**Code vs paper**
- [major] `dataset.py`: the prompt mechanism (the paper's main component) is commented out. The released code is the "w/o Prompt" model.
- [major] Multi-Ex: the "three retrieved metaphor examples" are three identical copies of one top-1 retrieval. No FAISS. The literal exemplar is static, not retrieved.
- [major] The exemplar candidate pool is the first 10 gold-labeled sentences per class of the file being processed. At test time, exemplars therefore come from the test set using its gold labels. Metonymy/simile exemplars are empty for binary test sets.
- [major] Encoder: deberta-large in `conf.py` vs DeBERTa-v3-base in the paper.
- [major] Checkpointing: the code selects on val_loss and then tests the final-epoch weights. The paper selects the best val macro-F1 checkpoint.
- [major] The paper says it follows official train/test splits for the binary benchmarks. The code trains one unified model whose training data overlaps heavily with the benchmark test sets (see above).
- [major] The VUA-18 and VUA-Verb test files contain the same 2,679 sentences with different labels.
- [minor] Class balancing: only literal is down-sampled to the metaphor count. Metonymy (409) and simile (621) stay ~10× smaller, while the paper says the four classes are balanced.
- [minor] No LR scheduler in the code (paper: linear).
- [minor] Gradient accumulation 2 (effective batch 32 vs paper 16).
- [minor] No projection layer z = W·h_CLS + b. SCL is applied to the raw CLS hidden state after dropout.
- [minor] `conf.py` references data files that are not released.

**Paper-internal**
- Table 4 ("Dynamic prompt + Multi-ex": Acc 81.8, F1 83.47) vs Table 1 ("Prompt + w/o Cont": F1 81.8, Acc 83.5): accuracy and F1 are swapped.
- Table 10: Simile Acc 99.88 with F1 99.99 on an all-positive test set is impossible (F1 would be 99.94). Table 3 gives 99.9/99.9.
- Sec. 5.2 says removing prompts drops VUA-Verb "from 88.9 down to 81.9". The w/o-prompt (+contrast) row is 87.7; 81.9 is the w/o-both row.
- The Introduction claims SOTA on MOH-X only; the Conclusion claims SOTA on VUA-Verb and MOH-X.
