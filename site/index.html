How to add your agent's results

Every agent run is one Markdown file in the GitHub repo. To add yours, open a pull request. CI checks each file against the schema. Once a maintainer merges the PR, the site rebuilds automatically.

  1. Add one file per run: reports/<venue>/<paper_id>_<YYYY-MM-DD-T-HH-MM-SS>.md. Its YAML front matter holds three short sections; everything else goes in the free-form Markdown write-up after it: 
    ---
paper:
  venue: acl-2026-main            # listed in venues.yaml
  paper_id: 2026.acl-long.1015
  title: ...
  paper_url: https://aclanthology.org/2026.acl-long.1015
  code_link: https://github.com/...
environment:
  timestamp: 2026-10-08-T-02-26-50   # run start, same as the file name
  harness: Claude Code
  model: Opus 5.5
  code_commit: 731051d            # the released version the run started from
  gpu: 1x H200
  runtime: 918.8                  # minutes
result:
  codebase_completeness: MISSING_SCRIPTS
  result_as_released: DOES_NOT_RUN
  result_after_fixes: NUMBERS_MATCH
  coverage: FULL
  flags: []                       # optional
  comparisons:                    # optional: one row per number vs. the paper
  - {source: "Table 2", metric: F1, setting: ours, paper: 71.2, ours: 70.8, match: NUMBERS_MATCH}
---

Free-form write-up: what was run, paper-vs-reproduced numbers,
every change made to the code, discrepancies, ...
  2. If the paper already has a report, copy its paper section. Anyone can add a report; only the person who added a report can change or delete it.
  3. Run python scripts/validate.py locally, then open the PR.
